# OpenSW AppImages

This repository builds unofficial AppImages for compiled releases from:

- [OpenTIE](https://github.com/elyosh/OpenTIE)
- [OpenXWA](https://github.com/elyosh/OpenXWA)
- [OpenXvT](https://github.com/elyosh/OpenXvT)
